# Michael Wang Photography

A fast, static photography portfolio built with Astro for `michael329666-del.github.io`.

## Local development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

The site is configured for automatic deployment to GitHub Pages from the `main` branch. Before the public launch, replace the temporary hero visual, collection placeholders, biography, and planned email address with final content.
